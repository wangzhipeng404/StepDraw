# StepDraw iPad（一笔一笔）

iPad 原生应用：**单界面自由绘制 + 加载图案轮廓临摹**。
与 [web 版](../web)共用同一份图案数据（远程 GitHub Pages），交互逻辑（三层画布、
笔画生长动画、视图变换、进度插值）均从 web 端移植到原生 Swift。

## 运行

1. 用 Xcode 15+ 打开 `StepDraw.xcodeproj`
2. 选择 iPad 模拟器或真机（iOS 17+）
3. 自动签名后直接运行

> 图案数据通过 `https://wangzhipeng404.github.io/StepDraw/data/` 远程拉取并本地缓存，
> 需联网；已下载的图案/缩略图缓存在 `Caches/StepDrawData/`。
> 如需换数据源，只改 `Services/DataStore.swift` 里的 `remoteBaseURL`。

## 界面布局

全屏画布 + 左侧抽屉式图案浏览（与 web 端 DrawingStudio / Android 端一致）。画布默认全屏（矩形，图案按适配变换居中留边距，边距区也能画）；
点顶部栏最左的 **logo** 从左侧滑出图案浏览抽屉（分组 → 分类 → 缩略图网格，搜索 / 难度筛选 / 分页），选中图案后自动收起。
工具栏全部使用 web 端同款 PNG 图标；颜色只有「自定义颜色」（原生取色器），无预定义色板，粗细滑块不显示"粗细"文字。

## 操作方式

| 模式 | 单指 / Pencil | 双指 |
|---|---|---|
| 绘制模式（默认） | 落笔绘制 | 捏合缩放 + 移动（落下第二指会结束当前笔） |
| 移动模式 | 拖拽平移 | 捏合缩放 |

- **自由绘制**：启动即空白画布，可直接画（内容坐标 = 屏幕坐标，支持缩放/平移）
- **加载图案**：点顶部栏最左的 **logo** 展开左侧抽屉（分组 → 分类 → 缩略图网格，搜索 / 难度筛选 / 分页），
  选中后载入画布并自动收起抽屉；淡色全轮廓作引导底图，已画步骤黑色，正在生长的笔画红色高亮
- 顶栏工具：笔种（钢笔/铅笔/马克/毛笔，选中换高亮图标，点已选中的笔退出绘制回到移动模式）·
  自定义颜色（原生取色器）· 粗细（滑块 + 数值）· 撤销/清除/复位，全部使用 web 端同款图标
- Pencil 悬停（不落下）显示笔尖预览；落下即开始绘制
- 播放控制：上一步 / 播放暂停 / 下一步 / 重播 / 倍速（0.5x/1x/2x）/ 进度条拖动
- 「轮廓」开关切换引导底图；「复位」恢复视图原始缩放与位置
- 「保存」导出完整作品（图案全步骤 + 你的笔迹，3x 分辨率）到相册；「分享」调起系统分享
- 「撤销」去掉最后一笔；「清空」清掉所有你的笔迹（图案数据不受影响）

### 渲染管线（与 web 端同构）

每帧（CADisplayLink @ 显示刷新率）：

1. 播放中则按"每秒 100 内容像素 × 倍速"推进当前步骤进度（长笔画画得久）
2. 引擎检查各离屏缓存是否失效（尺寸/图案/步骤/笔画数变化才重建）
3. 四层分别合成：
   - **outline**：淡色全轮廓 + 已完成步骤 + 当前笔画（按弧长截断到 progress，红色）
   - **history**：用户已完成笔画
   - **brush**：正在画的一笔
   - **pencil**：Pencil 悬停笔尖
4. 缓存位图整体做"缩放/平移"变换后 blit —— 手势时零重绘，只动变换

用户笔画以**图案内容坐标**存储（触点经视图逆变换还原），因此缩放/平移只是显示层
变换：视图复位后笔迹自动归位，导出永远按原始视图合成、不受缩放影响。
